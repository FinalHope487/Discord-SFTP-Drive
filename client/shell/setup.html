連線到你的 Discord Drive

這個 app 是視窗，硬碟本身跑在別的地方。填入伺服器的位址就會連過去。 This app is the window; the drive runs elsewhere.

改在這台電腦上執行（不需要另一台伺服器）→

Discord bot token 不在這裡填

token、頻道 id 與 MongoDB 帳密是伺服器的設定，寫在伺服器那台機器的 .env 裡，跟著 docker compose up -d 一起生效。它們不從這個畫面送過去： token 是伺服器的祕密，不是使用者的祕密，讓客戶端寫得到它就等於讓任何登入的人讀得到它。

從別的裝置連過來

預設只綁在伺服器自己的 127.0.0.1。要從這台以外的裝置連， 伺服器那邊的 .env.example 寫了三條路與各自的代價：
  1. 私人網路（Tailscale / WireGuard）— 兩邊各裝一個軟體，其他都不用改。
  2. 反向代理配真憑證（Caddy 兩行）— app 本身仍不上網路。
  3. LAN 明文 — 要同時改 WEB_BIND=0.0.0.0 與 WEB_COOKIE_SECURE=0，不建議。
