# that to the latest 4.x, which no longer imports. pymongo 4.9 removed the

# release from 4.9 up fails at "import motor.motor_asyncio". Verified against

# "pip check" does not catch this: the broken combination still satisfies the
# declared metadata. Revisit if motor is ever upgraded, since motor 3.6+
# supports pymongo 4.9+ and this pin would then be holding the stack back.
#

# non-ASCII character makes the install fail outright on non-UTF-8 consoles
# (cp950, cp1252, ...) before any package is resolved.
