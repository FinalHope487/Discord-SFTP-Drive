# 2026-08-10 · 授權條款是 Apache-2.0

**決策**：授權條款是 Apache-2.0

**依據**：
（2026-08-10）。選它不選 MIT 的理由是那段明確的免責聲明：
這是加密儲存工具，**使用者弄丟密碼就是永久失去資料**，「不負擔保責任」要是白紙黑字
而不是靠 README 的一行提醒；附帶的專利授權也比 MIT 完整。否決 AGPL——
這個專案希望被拿去用，不是希望管住拿去用的人。
**不逐檔加授權標頭**：Apache-2.0 不要求，`LICENSE` 檔就夠，84 個檔案各加 15 行
只是讓每個 diff 多一段噪音。**這一項不可逆**——已依此版取得程式碼的人永遠保有這個授權。
