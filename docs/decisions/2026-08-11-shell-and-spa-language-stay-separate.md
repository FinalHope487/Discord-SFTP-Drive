# 2026-08-11 · 外殼與檔案管理員的語言偏好維持獨立，不接起來

**決策**：外殼與檔案管理員的語言偏好維持獨立，不接起來

**依據**：
（2026-08-11，`QUESTIONS.md` 第 1 題，
選 A）。外殼兩頁的偏好在 `config.json`，檔案管理員的在 `localStorage`（`dd.lang`，
作用域是伺服器 origin）；SPA 由遠端伺服器提供，外殼不去碰它的 storage。
**代價是接受的**：在 setup 選了英文，開啟硬碟視窗之後 SPA 仍是它自己上次記得的語言，
要再切一次；换成外殼帶 `?lang=` 覆蓋的話，使用者在 SPA 裡切過的語言會被靜默蓋掉，
而他不會知道是誰蓋的——那個代價比「切兩次」更貴。

**反悔成本**：搬入時原文未單獨記錄（2026-10-04 自 `ROADMAP.md`〈已拍板的長期決策〉搬入）。
