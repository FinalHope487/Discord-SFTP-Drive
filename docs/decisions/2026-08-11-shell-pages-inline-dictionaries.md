# 2026-08-11 · 兩頁各自 inline 一份字典，不共用檔案

**決策**：兩頁各自 inline 一份字典，不共用檔案

**依據**：
（2026-08-11）。**這是 CSP 決定的，不是偷懶**：
這個視窗的 policy 是 `script-src 'unsafe-inline'`，沒有 `'self'`，所以
`<script src="i18n.js">` 會被擋。要共用就得放寬那道 policy，而那個視窗掛著特權 bridge。
代價其實不存在——兩頁沒有任何一句話是共用的，重複的只有二十行查表機制。
**翻譯字串裡只允許 `` `code` `` 與 `*bold*`，而且用 `createElement` 建成真元素，
不走 `innerHTML`**：翻譯是資料，資料不在特權頁面上被當成標記解析。
