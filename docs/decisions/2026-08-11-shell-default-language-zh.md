# 2026-08-11 · 外殼預設語言固定 `zh`，不跟系統語系走

**決策**：外殼預設語言固定 `zh`，不跟系統語系走

（2026-08-11，`QUESTIONS.md` 第 2 題，選 A）。

不是這一輪「決定要不要」的範圍。
