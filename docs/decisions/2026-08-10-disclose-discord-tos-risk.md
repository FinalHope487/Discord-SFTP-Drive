# 2026-08-10 · Discord ToS 的灰區風險明確揭露，不埋起來

**決策**：Discord ToS 的灰區風險明確揭露，不埋起來

**依據**：
（2026-08-10）。查證結論分三層：
一般 ToS **沒有**明文禁止拿它存檔案；但 Developer ToS 要求 API 使用符合文件用途、
不得超出速率限制，並保留在認為某開發者「對平台造成負面影響」時終止其存取的裁量權；
沒有找到針對這類專案大規模執法的公開紀錄。**所以它是灰區風險，不是已知違規。**
真正改變的是風險落在誰身上——開源之後是**每個自架者拿自己的帳號承擔**，
而他們多半不會去讀 Developer ToS。`README.md` 開頭因此有一節專講這件事，
包含「不要當唯一備份」與「用你賠得起的帳號」。代價只有 star 數，不寫的代價是別人的帳號。
