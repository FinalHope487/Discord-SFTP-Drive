**依據**：
（2026-08-06）。
刪除要能安全，前提是「還被引用的 message id」這個集合是完整的，而它是直接從 `nodes.chunks`
讀出來、沒有驗任何節點的 tag——所以能改資料庫的人只要拿掉一個 chunk 引用，就能讓這支工具

引用著，不是孤兒，歸 `sweep_incoming` 管。
