# 2026-08-03 · SFTP 認證：憑證存哪

**決策**：
單一使用者、`.env` 注入 `SFTP_USER` / `SFTP_PASSWORD`，
比對用 `hmac.compare_digest`。兩者皆無預設值，未設定會在啟動時直接失敗。
密碼同時是登入憑證與包裝主金鑰的密碼來源，所以有 12 bytes 的長度下限。
帳號現已是 `users` 的一列，但仍由 env 決定；多開帳號是上面的第 4 步。
