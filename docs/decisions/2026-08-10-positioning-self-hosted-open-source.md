# 2026-08-10 · 專案定位是「開源自架」，不是「我營運一個公開服務」

**決策**：專案定位是「開源自架」，不是「我營運一個公開服務」

**依據**：
（2026-08-10）。
每個人 clone 下來跑自己那一份，各自一個帳號、各自的 bot token。
**因此現有的單一帳號模型就是完成品，不是半成品**——多使用者第 4 步
（管理 CLI／建帳號流程／per-user 配額）維持 `[later]`，且**不預先承諾**；
「只能跑一個副本」在自架情境下不再是限制。日後要開公開服務是獨立決定，
屆時第 4 步、密碼救援路徑、配額與濫用處理、隱私政策全部才會變成阻塞。
